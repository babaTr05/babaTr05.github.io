## TikTok URL-Prefix Ownership Verification
To verify domain/URL-prefix ownership in the TikTok Developer Portal:
1. Download TikTok's verification signature file (for example, `tiktokXXXXXXXXXXXX.txt`).
2. Place that `.txt` file directly in the **root** of this repository (`babaTr05.github.io/`).
3. Commit and push to `main`. Because `.nojekyll` is present, GitHub Pages serves it directly at `https://babatr05.github.io/<filename>.txt` with HTTP 200 over HTTPS.
