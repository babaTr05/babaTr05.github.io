Privacy Policy

Effective Date: November 17, 2026 · Application: GTA Shorts Factory

Local-First Privacy Model: GTA Shorts Factory runs locally on the operator's computer. There is no central developer-operated cloud server collecting your videos, analytics, or OAuth tokens. This public website hosts only static informational and legal pages and does not set tracking cookies.

1. Information Processed by the Local Application

When you run GTA Shorts Factory on your machine, the Application processes only the data needed to perform video editing and authorized publishing:

  • User-Submitted Inputs: Source video URLs, framing/style preferences, custom hook text, and explicit rights confirmation flags.
  • Media & Transcript Data: Downloaded video segments, rendered 9:16 MP4 clips, thumbnails, and locally generated speech transcripts (.srt / transcript.json) stored under your local data/ directory.
  • Publishing Metadata: Video titles, descriptions, hashtags, creator attribution text, SHA-256 file hashes (used locally to prevent duplicate uploads), and rights verification audit logs.

2. TikTok OAuth Integration & Content Posting API

If you choose to connect a TikTok account for publishing Shorts:

  • Purpose & Scopes: The Application uses TikTok OAuth 2.0 credentials and the official TikTok Content Posting API v2 (open.tiktokapis.com/v2/post/publish/video/init/ and status/fetch/) solely to initialize video uploads, transfer your rendered MP4 file, set post metadata (caption/privacy), and poll upload processing status when you approve or schedule a post.
  • Direct Communication: API requests are sent directly from your local GTA Shorts Factory backend to TikTok's official endpoints. No intermediary developer server receives your TikTok tokens or video content.
  • No Unattended Unauthorized Posting: The publishing queue defaults to manual approval and enforces a local rights gatekeeper check before any upload is dispatched.

3. OAuth Token Storage & Security

  • Encrypted Local Storage: OAuth access tokens, optional refresh tokens, token expiration timestamps, and granted scopes are stored locally on your device in an SQLite database (data/publishing_tokens.sqlite3).
  • Encryption & Masking: Token payloads are encrypted at rest using symmetric Fernet encryption (derived via SHA-256 from SHORTSFACTORY_SECRET_KEY or the local machine configuration). Secrets are masked in UI responses and logs.
  • Static Website Isolation: This GitHub Pages website does not receive, store, or process any OAuth tokens, API keys, or user media.

4. Third-Party APIs Configured by the Operator

Depending on which optional API keys you configure in your local .env file, the Application may send requests directly from your computer to:

  • Google Gemini API: Video URLs/inputs for highlight timestamp analysis (when GEMINI_API_KEY is set).
  • YouTube Data API v3: Public search/channel/video metadata queries (when YOUTUBE_API_KEY is set) and YouTube Shorts uploads (when YouTube OAuth is connected).
  • TikTok, Instagram, and X APIs: Video uploads and status checks when you connect those accounts.

Each third-party provider handles data under its own privacy policy.

5. Data Retention

All job records, cached video segments, rendered clips, audit logs, and encrypted OAuth tokens remain on your local storage until you delete them or until configured local cache retention rules clean up old downloaded segments.

6. Account Disconnection & Data Deletion

You can disconnect your TikTok account and delete your data at any time:

  • Disconnect in App: In the local GTA Shorts Factory UI under the Publishing tab, click Disconnect next to TikTok (or call DELETE /api/publishing/platforms/tiktok). This immediately deletes the encrypted TikTok OAuth token record from data/publishing_tokens.sqlite3.
  • Revoke in TikTok: You can also revoke GTA Shorts Factory's access at any time from your TikTok app under Settings and privacy → Security and permissions → Apps and services.
  • Delete Local Data: To erase all local jobs, cached clips, publishing queues, and audit logs, delete the local data/ directory on your machine.

7. Changes to This Privacy Policy

We may update this Privacy Policy to reflect changes in the Application or supported integrations. Any updates will be published on this page with an updated effective date.
