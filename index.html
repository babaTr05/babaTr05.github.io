Core Capabilities

Smart 9:16 Framing Engine

Automatically frames 1080×1920 vertical video using Smart Fill, Blurred Background, Streamer Focus, Gameplay Focus, and Dynamic Focus layouts with MediaPipe/OpenCV facecam detection and platform UI safe margins.

Economic Partial Retrieval

Analyzes source timestamps with Gemini before retrieving only selected highlight intervals via yt-dlp, keeping bandwidth, storage, and API costs low.

Six Narrative Shorts Styles

Supports Single Highlight, Ranking / Top N (including multi-source compilations with creator attribution), Realization / Discovery, Funny Compilation, Streamer Reactions, and Epic Moments.

Grounded Viral Hooks & Subtitles

Generates and ranks contextual opening hooks grounded in actual transcript speech and audio events—without fabricating quotes—alongside local speech transcription.

Optional Music Post-Processing

Disabled by default. Mixes authorized or royalty-free tracks post-render with speech-aware ducking and -c:v copy remuxing while preserving the clean MP4 export.

Rights-First Social Publishing

Integrates with official APIs (TikTok Content Posting API, YouTube Data API, Instagram Reels, and X) using a local manual-approval queue and strict content rights verification.

How the Local Pipeline Works

Authorized Source URL → AI Highlight Analysis → Partial Segment Retrieval → Local Verification (Facecam / Audio / Speech) → Smart 9:16 Framing & Hook → Clean MP4 Render → Optional Music → Manual Approval Queue → Official Platform API
Local-First Architecture: GTA Shorts Factory runs on your own workstation. OAuth tokens and job databases stay encrypted on your local machine—never on a third-party SaaS server.
